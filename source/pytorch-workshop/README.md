## Setup

### Install dependencies

```bash
# clone project
git clone https://github.com/altndrr/pytorch-workshop
cd pytorch-workshop

# (recommended) use uv to set up the python version
# and to install the required dependencies
curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync --frozen

# (alternative) use conda to set up the python version
# and pip to install the required dependencies
conda create --name py3.12 python=3.12
conda activate py3.12
python -m venv .venv
.venv/bin/python3 -m pip install -e .

# activate virtual environment
source .venv/bin/activate
```

### Setup environment variables

```bash
# copy .env.example to .env
cp .env.example .env

# edit .env file
vim .env
```

## Inference

### Examples

You can find examples on how to run basic models/agents in the `examples/` folder. They all roughly follow the same structure and have the same arguments. For example, to run Kosmos (i.e., an image captioning model), you can run the following:

```sh
# execute the default image captioning model on the given input image
python -m examples.image_captioning --input PATH_OR_URL_TO_IMAGE

```

Similarly, you can do the same for the other scripts in the folder.

If you want to check the full list of options for each script, simply use the `--help` flag.

### Server-client

We additionally provide a server-client interface to enable running models on a remote server and call their execution from a client. To start the server, run the following:

```sh
# start the server locally
python server.py

# start the server and make it visible on all interfaces
# (required when the server and client are on different machines)
python server.py --host 0.0.0.0

```

Currently, we do not provide a client script entrypoint, but it is easy to instantiate one in any script/notebook/interactive session with the following snippet of code:

```python
from src import chat_settings
from src.client import Client

# update the host to point to the server address
# e.g., instead of "127.0.0.1" (default), use "iasi.disi.unitn.it"
chat_settings.HOST = input("Input the host address: ")
client = Client(chat_settings.BASE_URL)

# check the server metadata
print(client.info)

# to make an async transformers request, you can use the following
out = await client.atransform(PATH_OR_URL_TO_IMAGE, MODEL_NAME)
out.pretty_print()

# to make an sync transformers request, you can use the following
out = client.transform(PATH_OR_URL_TO_IMAGE, MODEL_NAME)
out.pretty_print()
```

The codebase additionally support calling agents on user inputs with the `client.ainvoke` and the `client.invoke` methods.

For image segmentation models, the output is a base64-encoded image, so to interpret their output, you should run the following:

```python
import base64
import io

import matplotlib.pyplot as plt
from PIL import Image

# read the content in the response of the `.atransform`/`.transform` method
image_base64 = out.content

# decode the image
image_data = base64.b64decode(image_base64)
image = Image.open(io.BytesIO(image_data))

# visualize the image
plt.imshow(image)
plt.axis("off")
plt.tight_layout()
plt.show()
```

## Development

### Install dependencies

```bash
# (recommended) use uv to install the dependencies
uv sync --frozen --extra dev

# (alternative) if you have install dependencies with pip
# install the required dependencies for development
.venv/bin/python3 -m pip install -e .[dev]
```

### Install pre-commit hooks

```bash
# install pre-commit hooks
pre-commit install
```

### Run tests

```bash
# run fast tests
make test
```

### Format code

```bash
# run linters
make format
```

### Clean repository

```bash
# remove autogenerated files
make clean

# remove logs
make clean-logs
```
